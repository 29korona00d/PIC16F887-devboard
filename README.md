# PIC16F887-devboard
This is a development board with the Microchip PIC16F887 microcontroller. It contains the chip, a CH340 USB-UART chip, and multiple peripherals.
the PicKit programming pins are connected to pin headers for burning the bootloader in, which is the tiny multi bootloader. Then, it can be programmed through the USB-C. I also included a barrel jack for power supply in case the PC's USB port cant supply enough.
